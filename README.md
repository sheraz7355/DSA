# DSA in C++

My C++ practice while following Shradha Khapra's **DSA Series** (Apna College).
One folder per lecture. Swift solutions live in [DSA-Swift](https://github.com/sheraz7355/DSA-Swift).

| Folder | What's inside |
|---|---|
| `lecture-03-conditionals-and-loops` | sums, min/max, primes, uppercase check, homework |
| `lecture-04-patterns` | square, triangle, pyramid, Floyd's, hollow diamond, butterfly |
| `lecture-05-functions` | factorial → nCr, fibonacci, primes up to n, sum of digits |
| `lecture-06-binary-numbers` | binary ↔ decimal |
| `lecture-08-arrays` | linear search, reverse, smallest/largest, intersection |

New lecture → new folder, named like `lecture-13-stock-and-pow`.

## Run a file (vim + g++)

```
g++ -std=c++17 lecture-04-patterns/floyd-triangle.cpp && ./a.out
```

`a.out` and other build files are ignored by git.
